# 智学伴 · 实机演示脚本

> 边操作边讲，建议 3-5 分钟。以下每个编号是你要说的一句话，括号里是要做的操作。

---

## 一、开场（30秒）

**操作：** 打开 Vercel 部署的页面，停留 3 秒

1. "大家好，这是智学伴——一个基于生成式 AI 的异步学习平台。"
2. "它用'以教促学'的理念，让学生在学完后向 AI 讲解知识点，讲通了才算掌握。"
3. "下面我演示一下完整的学习流程。"

**操作：** 点击设置页，展示已配置 API Key（不用透露 Key 内容）

4. "首先需要配置 API Key，支持 OpenAI、DeepSeek、通义千问等主流模型。也可以在这里选择出题难度——从简单到挑战一共四档。"

---

## 二、创建课程（40秒）

**操作：** 进入课程创建页

5. "创建课程很简单——输入你感兴趣的主题，比如'二次函数'，AI 自动生成章节结构。"
6. "也可以直接上传 PDF 课件，AI 会自动提取知识点并拆分成章节和小节。"

**操作：** 返回课程列表，展示已有课程和进度条

7. "这里是我之前创建的几门课，每门课都有进度显示。"

**操作：** 点进一门课

---

## 三、学习闭环（90秒）

**操作：** 展示目录结构，点击一个小节

8. "进入课程后，左边是章节目录，右边是学习内容。整个学习是一个六阶段闭环：预习阅读、小测验、AI 批改、针对性练习、以教促学，最后通关。"

**操作：** 进入预习阅读阶段，滚动展示讲义内容

9. "首先是预习阅读——AI 自动生成讲义，支持 LaTeX 公式和 Markdown 排版。"

**操作：** 滚动到有函数图像的部分

10. "重点是，讲义里可以直接嵌入函数图像。抛物线、双曲线、分段函数、甚至三维曲面，AI 都能自动生成。这是文字 AI 加上我们自建的数学渲染引擎实现的——不需要图像生成模型，成本低、精度高。"

**操作：** 点击"开始小测"，展示题目

11. "阅读完成后进入小测验。每道题右上角标注了难度星级，从 1 到 6 星。"

**操作：** 做题 → 提交 → 展示批改结果

12. "提交后 AI 逐题批改，给出详细解题步骤和薄弱点分析。"

**操作：** 点击"针对性练习"

13. "根据薄弱点，AI 自动生成针对性练习，避免重复原题。"

---

## 四、以教促学（60秒）⭐核心亮点

**操作：** 进入以教促学界面，展示错题卡片

14. "接下来是最核心的环节——以教促学。"

**操作：** 在输入框打字，模拟讲解过程

15. "这里 AI 扮演的是学生角色。你需要向 AI 讲解你的解题思路，它会追问、验证你是否真的理解了。"

**操作：** 展示 AI 追问，然后回复，直到 APPROVED

16. "只有讲通了，AI 才会回复'✅ APPROVED'。这杜绝了抄答案的可能——因为 AI 等的是你的讲解，不是你的答案。"

**操作：** 展示收藏弹窗

17. "通过后可以选择收藏这道题，连同对话记录一起保存到收藏夹。"

---

## 五、其他功能（30秒）

**操作：** 快速过一遍

18. "还有几个配套功能——"

**操作：** 依次点：试卷系统 → AI 学习助手 → 错题集 → 收藏夹

19. "试卷系统支持 AI 出卷和导入试卷、倒计时考试。右下角有 AI 学习助手，学习中随时提问。错题集自动收集所有错题。收藏夹保存教促学通过的题目和对话记录。"

---

## 六、收尾（20秒）

**操作：** 回到首页

20. "最后说一下——这个平台零服务端成本，数据全部存在浏览器本地，不需要注册账号。"
21. "支持网页版、Vercel 一键部署和 Windows 桌面 EXE，有 Python 就能用图形渲染，没有 Python 会自动降级纯文字模式。"
22. "智学伴——让 AI 成为每个学生的私人助教。谢谢。"

---

## 录制前准备

- [ ] 确保 Vercel 部署可访问（或本地 `npm run dev`）
- [ ] 提前创建好一到两门课程，确保有学习进度
- [ ] 确保以教促学有一道待讲解的错题
- [ ] 设置页 API Key 已配置（遮住 Key 内容）
- [ ] 难度设置选一个明显的（如"进阶"）
- [ ] 关闭浏览器书签栏、无关标签页
- [ ] 录屏区域 16:9，分辨率 1920×1080
